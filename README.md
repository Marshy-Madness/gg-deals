# gg.deals for Decky

Shows the lowest current price from [gg.deals](https://gg.deals) as a badge on Steam store app pages in Gaming Mode. Tap the badge to open the game on gg.deals.

## Setup

1. Get a free API key at https://gg.deals/api/
2. Open the plugin in the Quick Access Menu, paste the key, and pick your region.
3. Turn off **Include keyshops** if you only want official store prices.

Prices are cached for 30 minutes per game.

## Build

```sh
pnpm install
pnpm build
```
